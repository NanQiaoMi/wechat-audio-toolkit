## 风险提示

1. **类目/审核风险**：音频处理工具 + “转发给好友”可能被要求补充资质或调整类目；如被拒，按审核意见改为“仅本地试听/不提供转发”或补充说明。
2. **内容安全风险**：个人主体无异步媒体检测权限，需控制传播范围并准备人工处置。
3. **长音频风险**：30min MP3 接近 60s 超时；M4A/OGG/AAC 长文件已限 10min。
4. **并发/成本风险**：免费额度 5 次/日 + 1 CPU 云函数，突发流量可能超时或产生费用。
