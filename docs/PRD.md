## 1. 背景与问题

微信已经成为音频文件的中转站：聊天里会收到 `.m4a` 语音备忘录、`.flac` 无损音乐、`.amr` 旧语音、`.ogg` 游戏音频、`.wav` 录音、`.mp3` 伴奏……但车载 U 盘、办公系统、老播放器、部分上传平台只认 MP3 等少数格式。

用户目前的替代方案都有明显缺点：

| 方案 | 问题 |
| :--- | :--- |
| 电脑软件（格式工厂/Audacity） | 要开电脑、安装包大、学习成本高 |
| 网页转换工具 | 广告多、上传慢、隐私风险、手机操作不便 |
| 下载 App | 使用频率低、占空间、注册麻烦 |
| 微信里直接改扩展名 | 文件实际编码没变，多数场景仍不可用 |

**机会**：在微信内完成“选文件 → 选格式 → 转换 → 试听/转发”的闭环工具，无需安装、无需电脑，符合高频小需求。

## 2. 产品定位与目标

### 2.1 一句话定位

> 微信里的轻量音频格式转换器：把聊天里的音频转成通用格式，直接试听、转给好友或拿到电脑上。

### 2.2 产品目标

1. **可用**：常见音频格式互转成功率 ≥97%，转换结果可试听、可转发。
2. **可信**：文件仅用于转换、24 小时内删除；有隐私说明与版权提示。
3. **合规**：类目、备案、隐私、内容安全全部满足微信要求，可稳定上线。

### 2.3 成功指标（MVP）

| 指标 | 目标 |
| :--- | :--- |
| 任务成功率 | ≥97% |
| 端到端 P95 | ≤60s（10MB / 5min，4G） |
| 首次使用完成率 | ≥50%（进入首页→成功转换） |
| 审核 | 一次通过 |
| 崩溃率 | <0.5% |
| 分享/保存成功率 | ≥95%（按平台能力） |

### 2.4 非目标（MVP）

- 不提供曲库、音乐搜索、在线听歌、公开分享、社区。
- 不做端内转码（技术不可行）。
- 不做专业剪辑（多轨、混音、降噪、母带）；**MVP 不含剪辑**，V1.1 的「简单音乐剪辑」见 [MUSIC_EDITOR_DESIGN](./MUSIC_EDITOR_DESIGN.md)（单主轨+配乐，非 DAW）。
- 不做批量/视频转音频；铃声/变速/编辑能力进入 V1.1（范围与限额见设计文档）。
- 不承诺“保存到手机音乐库/相册”（平台无音频 API）。
- 免费、无广告、不接虚拟支付（用户 2026-10-27 决策；个人主体也不支持虚拟支付）。

## 3. 用户与场景

### 3.1 目标用户

| 用户 | 特征 | 核心诉求 |
| :--- | :--- | :--- |
| 普通微信用户 | 收到语音/录音文件，需转 MP3 发给别人或上传 | 简单、快、不用装 App |
| 音乐爱好者/创作者 | 有 FLAC/APE/WAV 资源，想压缩成 MP3 分享 | 高音质选项、体积可控 |
| 办公/学生 | 会议录音、讲座音频需转通用格式 | 稳定、可试听、可保存到电脑 |
| 旧设备用户 | 车载/MP3 播放器只认 mp3/wav | 兼容性优先 |

### 3.2 典型场景

1. 同事在群里发了一段 `.m4a` 会议录音，用户想转成 MP3 存到电脑。
2. 用户拿到一首 `.flac` 伴奏，想压成 320k MP3 发到群里。
3. 用户自己录了一段语音备忘（aac），想转成 wav 给剪辑软件。
4. 用户收到 `.amr` 老语音，想在 Android 上转成 MP3 保存。
5. 用户想把 `.wav` 大文件压小，方便微信发送。

### 3.3 用户旅程（MVP）

```text
打开小程序 → 看到“选文件”与使用说明
  → 从微信聊天选择音频（或录音）
  → 看到文件信息/试听（平台支持时）
  → 选择目标格式（默认 MP3）与音质
  → 点击“开始转换” → 上传 → 云端转码 → 进度
  → 结果页试听、转发给好友/文件传输助手、PC 保存
  → 历史记录（本地）可再次转发/重试
```

## 4. 关键产品约束（必须写进 UI 与文案）

| # | 约束 | 对产品的含义 |
| :--- | :--- | :--- |
| 1 | 小程序只能从**微信会话文件**或**录音**获取音频，不能浏览手机文件 | 首页首屏即说明；提供“先发给文件传输助手再回来选”的引导；不做假的“本地文件”入口 |
| 2 | iOS 不能直接播放 flac/ogg/amr/ape/wma | 输入这些格式时提示“需先转 MP3 试听”；输出默认 mp3/m4a/wav；高级格式标注平台限制 |
| 3 | 手机端无法直接保存音频到系统目录 | 不出现“保存到手机”按钮；只提供“转发给好友/文件传输助手”“PC 保存”“复制临时链接” |
| 4 | 云端转码必须异步（`callContainer` timeout 上限 15s） | 进度页必须存在；不能设计“点击后一直转圈等结果”的同步交互 |
| 5 | 内容安全异步检测（≤30min） | 先转换后检测；命中 risky 删除产物并提示；隐私政策说明 |
| 6 | 单文件建议 ≤50MB、时长 ≤30min | 大小本地拦截；时长由服务端 ffprobe 校验，超限拒绝并返还额度 |
| 7 | 类目“工具>图片处理”不得传播分享/公开访问 | 不做公开链接/社区/榜单；转发仅限用户点击发给自己好友 |
| 8 | 个人主体不能开通虚拟支付 | MVP 免费+限额；不做付费墙 |

### 6.2 首页布局（自上而下）

1. 标题区：产品名 + 一句话价值 + “支持格式”标签。
2. 导入区：大按钮“从微信聊天选择音频”；次级“录音转格式”；说明“手机本地文件请先发给文件传输助手”。
3. 已选文件卡片：文件名、大小、格式徽章、时长（可获取时）、试听条、删除/重选。
4. 转换设置：目标格式栅格（MP3 默认/ M4A / WAV / FLAC / OGG）；预设（标准/省流/高保真）；高级折叠（码率/采样率/声道）。
5. 主按钮：“开始转换”；下方小字：单文件 ≤50MB、≤30 分钟、文件 24 小时删除。
6. 底部：历史入口、设置入口、隐私/协议入口。

### 6.3 任务页

- 步骤条：上传 → 排队 → 转码 → 安全检测 → 完成。
- 进度百分比（服务端语义进度 + 客户端预计）。
- “取消任务”；失败时显示错误文案 + 重试。
- 冷启动/排队文案：“正在准备转码服务，请稍候”。

### 6.4 结果页

- 成功标识 + 文件名（转换后）。
- 大小对比：`12.4MB → 3.2MB（节省 74%）`。
- 参数摘要：格式/码率/采样率/声道/耗时。
- 结果试听器（平台支持时）；“原文件”切换对比。
- 操作按钮：
  - **转发给好友**（主）：`wx.shareFileMessage`，点击触发。
  - **保存到电脑**（PC 微信可见）：`saveFileToDisk`。
  - **复制下载链接**：PC 临时链接（2h），标注有效期。
  - **再转一个**：回到首页。
- 安全状态：检测中/通过/未通过（未通过隐藏导出并说明原因）。

### 6.5 历史页

- 本地最多 20 条，按时间倒序。
- 字段：文件名、格式变化、大小、时间、状态（成功/失败/已过期/安全拦截）。
- 操作：试听、转发、重试、删除；底部“清空历史”。
- 超过 24h 的记录标记“文件已清理”，仍保留元信息。

## 7. 功能需求（FR）

> 优先级：P0 = MVP 必须；P1 = MVP 应有；P2 = 可延后。验收标准中的“平台限制”以 TASK_PLAN §3 为准。

### FR-01 会话文件导入（P0）

- 入口：首页主按钮。
- 规则：`wx.chooseMessageFile({count:1,type:'file',extension:[...]})`；扩展名白名单（mp3/wav/m4a/aac/flac/ogg/amr/ape/wma/aiff）；选择后展示文件名/大小/格式。
- 校验：>50MB 立即拦截；未知扩展名提示可尝试但以服务端探测为准；损坏文件在转码阶段返回明确错误。
- 异常：用户取消不报错；接口失败提示重试；低版本基础库引导升级。
- 验收：iOS/Android/PC 各选 1 个合法文件成功进入下一步；取消/超限/非法文件均有提示；不做“手机本地文件”入口。

### FR-02 录音导入（P1）

- 入口：首页次级按钮“录音转格式”。
- 规则：`RecorderManager.getRecorderManager()`；默认 aac，可选 mp3/wav；最长 10 分钟；开始前申请麦克风权限；录制中可暂停/停止/取消；结束后可试听。
- 异常：拒绝授权时提示去设置；录制中断保留已录部分（若平台支持）。
- 验收：录制 → 试听 → 转换全流程通过；权限拒绝有引导。

### FR-03 文件信息与预检（P0）

- 展示：文件名（超长省略+可展开）、大小、格式徽章、时长（能获取时）。
- 服务端预检：`ffprobe` 校验真实格式/时长/音轨；失败给可操作错误。
- 安全：不在客户端解析二进制；不信任扩展名。
- 验收：改扩展名的文本文件被拒绝；0 字节文件被拒绝。

### FR-04 源音频试听（P0）

- 规则：`InnerAudioContext`；播放/暂停/进度拖动/时间；页面卸载或切文件时 `destroy()`；iOS 不支持格式提示“转换为 MP3 后可试听”。
- 验收：连续切换文件无重叠播放；退出页面无后台声音；内存无泄漏。

### FR-05 输出格式与参数（P0）

- 格式：MP3（默认，兼容性最好）、M4A（iOS 友好）、WAV（无损但大）、FLAC（无损压缩，高级）、OGG（高级，部分设备不可试听）。
- 预设：
  - 标准 MP3：192kbps / 44.1kHz / 立体声；
  - 省流 MP3：128kbps / 44.1kHz / 立体声；
  - 高保真 MP3：320kbps / 44.1kHz / 立体声；
  - 移动端通用：M4A 192kbps / 44.1kHz / 立体声；
  - 无损 WAV：PCM 16bit / 44.1kHz / 立体声（二次确认体积）。

> 说明：以上为 3 档 MP3 音质预设 + M4A/WAV 各一个默认参数；FLAC/OGG 使用格式默认参数，不展示码率档。
- 高级：码率（128/192/256/320）、采样率（保持原/44.1k/48k）、声道（立体声/单声道）。
- 规则：部分组合不可用（如 WAV 不显示码率）时禁用并解释；默认值随源文件尽量保留。
- 验收：默认值正确；非法组合不可提交；结果参数与选择一致（服务端返回校验）。

### FR-06 上传文件（P0）

- 规则：先向服务端申请上传票据（票据绑定本次任务与用户），再用 `wx.cloud.uploadFile({cloudPath, filePath, config:{env}})` 直传；展示上传进度；失败可重试；用户可取消。
- 约束：上传直传对象存储，不经过业务服务；单文件上限待实测（初始按 50MB 设计）。
- 验收：弱网重试成功；取消后无脏文件（服务端清理）；进度条准确。

### FR-07 创建与轮询任务（P0）

- 规则：`POST /v1/tasks` 创建；响应含 taskId；客户端每 1.5s 轮询，逐步退避至 3s；页面隐藏暂停轮询、返回恢复；超过 5 分钟提示失败可重试。
- 恢复：taskId 存本地，重新进入可继续查询；避免重复创建。
- 验收：网络切换/切后台/杀进程后能恢复；不产生重复任务；轮询无泄漏。

### FR-08 进度与状态展示（P0）

- 状态：上传中、排队中、转码中、安全检测中、成功、失败、已取消。
- 进度：服务端返回语义进度（10/30/55/80/95/100），客户端可平滑展示；冷启动给“准备中”提示。
- 验收：每个状态有文案、图标、可执行动作；状态与服务端一致。

### FR-09 结果与试听（P0）

- 展示成功、文件名、大小对比、参数摘要。
- 结果试听：优先 mp3/m4a/wav；flac/ogg 在 iOS 提示不可试听。
- 验收：试听正常；没有声音/文件损坏时有错误提示。

### FR-10 导出：转发给好友（P0）

- 规则：用户点击“转发给好友” → `wx.cloud.downloadFile` 拿临时路径 → `wx.shareFileMessage({filePath, fileName})`；必须由点击触发。
- 文案：说明“将发送到所选聊天；对方能否直接播放取决于格式与设备”。
- 异常：下载失败提示重试；分享取消不报错。
- 验收：iOS/Android 发送到文件传输助手成功；文件名正确；不出现公开分享。

> 用户决策（2026-10-27）：**坚持保留“转发给好友”**。提审时说明这是用户对自有文件的私聊发送，不提供公开链接/社区/公开传播；若审核仍拒绝，再启用降级方案。

### FR-11 导出：PC 保存 / 临时链接（P1）

- PC 微信：`wx.saveFileToDisk` 保存到电脑。
- 移动端：提供“复制 PC 下载链接”（`getTempFileURL`，按 2h 申请；云托管对象存储默认 86400s），标注“仅电脑浏览器可用/限时有效”。
- 验收：PC 保存成功；链接在有效期内可下载；过期有提示。

### FR-12 历史记录（P1）

- 本地 storage 最多 20 条；字段见 TASK_PLAN §8.2；超过 24h 标记文件已清理；支持试听（文件未过期时）、转发、重试、删除、清空。
- 验收：重启小程序记录仍在；清理缓存后为空；不记录敏感 URL。

### FR-13 设置与协议（P1）

- 内容：用户协议、隐私政策、版权声明、侵权投诉入口（邮箱/客服）、关于（版本/技术说明）、清理缓存。
- 验收：协议可打开；投诉入口可触达。

### FR-14 隐私授权（P0）

- 首次使用前展示隐私弹窗；同意后才能选择文件/录音；拒绝时说明影响并可再次触发。
- 后台隐私指引与代码调用一致（收集选中的文件；录音则麦克风）。
- 验收：未同意无法使用；同意记录可查询；审核截图材料齐全。

### FR-15 内容安全（P0）

- 创建任务后立即对输入送检（与转码并行，不阻塞转换）；送检对象 ≤10MB 且格式受支持；否则按时长自适应生成 ≤10MB mp3 代理（30min 用 32kbps 单声道 ≈7.2MB），仍超限则截取片段并在协议中说明为抽检。
- 结果：pass 记录；risky 删除输出、任务标记失败/拦截、历史显示“安全限制”；review 进人工队列/按 risky 保守处理。
- **已知窗口期**：MVP 允许检测结果返回前试听/下载，命中 risky 后删除并阻断后续导出；该策略需在提审说明与用户协议中披露。若审核要求“检测通过前不得导出”，则降级为导出按钮等待检测结果（体验变差，需产品确认）。

> 用户决策（2026-10-27）：**接受该窗口策略**；提审材料需主动说明检测机制与删除/投诉链路。
- 用户提示：不展示具体违规细节，提供“文件未通过安全检查”说明。
- 验收：命中后产物不可下载/转发；台账可查；不泄露检测细节。

### FR-16 额度与限流（P0）

- 规则：测试阶段不限次数；后端保留 `QUOTA_ENFORCED` 开关，恢复时可设每日 5 次；并发 1；分钟级频率限制；失败任务返还额度；跨天重置。
- 提示：剩余次数展示在首页；超限给明确文案与重置时间。
- 验收：超限被拦截；失败返还；并发重复点击不重复扣次。

### FR-17 错误与降级（P0）

- 统一错误码（TASK_PLAN §8.3）；网络/服务/存储/超时分类；每类有可操作文案与重试入口；不白屏、不死循环。
- 验收：断网、云服务不可用、任务丢失、文件过期均可恢复或明确说明。

### FR-18 统计与反馈（P1/P2）

- 埋点事件：首页曝光、选文件、上传开始/成功/失败、任务创建、转码成功/失败、转发、PC 保存、历史点击、错误码。
- 反馈入口：设置页“意见反馈”（可用微信客服/表单；P2 可接客服消息）。
- 验收：核心漏斗可计算；不含敏感内容。

### FR-19 音乐剪辑（已落地 MVP；详细设计见 [MUSIC_EDITOR_DESIGN](./MUSIC_EDITOR_DESIGN.md)）

- 定位：用户自有音频的简单剪辑工具（非专业 DAW、无曲库/无在线听歌/无公开分享）。**2026-10-28 已作为第二 tab 与格式转换合并上线 MVP v2**（多源导入 ≤5、片段时间线/拼接/分割/裁剪/删除、每片段独立淡入淡出、跨源预览、全局音量、导出 MP3）。
- 范围：导入（会话文件 **P0 ≤3 源**，SPIKE 后 ≤5；录音 ≤10min）→ 服务端分析（时长/peaks/分平台可播标记）→ 波形编辑（裁剪、删除、片段排序、整体淡入淡出、音量、变速；**P0 含铃声模板**）→ 导出 mp3（默认）/wav/flac（P1：拼接/配乐；m4a P1；OGG 不支持）。
- 约束：编辑源/成片均 ≤10min；P0 主轨源总时长 ≤900s；WAV 输出 ≤4min、FLAC ≤7min；**额度与 v1.0 共用开关**（测试期不限次数 `QUOTA_ENFORCED=false`；正式期建议与转换共享每日 5 次，导出成功扣 1、失败返还）；24h 清理；内容安全沿用 v1.0。
- 预览：InnerAudioContext 顺序播放 + 音量渐变近似（**近似预览，以导出文件为准**）；iOS 不可播格式提示「可编辑、不可试听，或先转 MP3」。
- 验收：以设计文档 §16 的 Given/When/Then 为准；开发前须完成 §13.3 真机 Spike。

## 9. 核心流程

### 9.1 首次使用

```text
打开 → 隐私弹窗（同意/拒绝/查看协议）→ 首页说明 → 选文件 → 文件卡片 → 选格式 → 开始转换 → 任务页 → 结果页 → 转发/PC 保存
```

### 9.2 转换主流程（含异常）

```text
选择文件（校验大小/扩展名）
 ├─ 失败 → 提示原因 + 重选
上传（进度）
 ├─ 失败 → 重试/取消
创建任务
 ├─ 失败 → 重试（幂等）/返回
轮询
 ├─ 超时 → 失败页 + 重试（保留 taskId）
 └─ 成功 → 结果页
```

### 9.3 内容安全

```text
创建任务后 → 立即送检（与转码并行；≤10MB 原文件或按时长自适应代理）
          → 转码成功：结果页可试听/下载（标注“安全检测中”）
          → 回调 pass：无感
          → 回调 risky：删除云端产物、历史标记、提示用户；后续导出被拒
```

### 9.4 额度与失败返还

- 扣次时机：任务创建成功（queued）。
- 返还：转码失败/超时/服务异常；内容安全 risky 不返还（可申诉）。
- 跨天：按北京时间 0 点重置。

### 9.5 退出与恢复

- 任务中退出：taskId 存本地；再次进入首页显示“有进行中的任务”，点击恢复轮询。
- 超过 24h：任务/文件过期提示重试。
