# 音乐音频格式转换小程序 - 任务规划与开发路线图 (TASK_PLAN)

## 1. 规划目标与技术基线
本项目遵循微信官方 [微信云开发快速开始指引](https://developers.weixin.qq.com/miniprogram/dev/wxcloudservice/wxcloud/basis/getting-started.html) 标准，基于**微信小程序原生前端 + 微信云开发 (CloudBase)** 构建端到端的全格式音频转换工具。

---

## 2. 阶段任务拆解与里程碑 (Milestones)

```
阶段一：需求设计与云开发基准对齐 [已完成]
   ├── PRD 产品规格说明书建立 (基于微信官方规范)
   ├── 云开发架构设计 (Cloud Storage + Cloud Functions + Cloud DB)
   └── 开发日志系统与规范初始化

阶段二：微信云开发环境与转码云函数构建 (里程碑 1)
   ├── 微信开发者工具开通「云开发」环境配置引导
   ├── 建立 audioConvert 云函数骨架与 Node.js 依赖管理
   ├── 集成静态 FFmpeg 跨平台可执行二进制并封装转码核心
   └── 云存储临时文件隔离与 24h 生命周期清理机制

阶段三：前端交互界面与格式选择器 (里程碑 2)
   ├── 现代化卡片式 UI 布局设计 (符合微信 Design 规范)
   ├── 微信原生文件拾取器 (wx.chooseMessageFile) 深度集成
   ├── 多格式六宫格单选卡片 (MP3, WAV, M4A, AAC, FLAC, OGG)
   └── 高级音质抽屉 (比特率、采样率、声道自定义)

阶段四：音频试听播放器与全链路转码串联 (里程碑 3)
   ├── 原生双轨音频控制器 (基于 InnerAudioContext 封装)
   ├── 文件直传云存储 (wx.cloud.uploadFile) 进度动效
   ├── 云函数转码状态流转机 (上传中 -> 云端转码中 -> 转换成功)
   └── 压缩效果对比卡片 (体积增减、转码耗时统计)

阶段五：微信生态导出分享与历史记录管理 (里程碑 4)
   ├── 一键发给微信好友 (wx.shareFileMessage) 闭环
   ├── 本地文件持久化与外部打开 (wx.openDocument)
   └── 转换历史记录本地持久化 (wx.setStorage) 与快捷复用

阶段六：边界异常测试与发布就绪 (里程碑 5)
   ├── 超大文件 (50MB) 与损坏文件拦截测试
   ├── iOS / Android / PC 微信多端实测与兼容性修复
   └── 云函数正式部署与代码审核上架准备
```

- [x] **T1.4** 对齐官方微信云开发快速开始文档，设计云函数与云存储数据流

### 阶段二：云开发环境与核心转码云函数
- [ ] **T2.1** 配置项目 `miniprogram/app.js` 的云开发初始化逻辑，支持动态与指定环境 ID。
- [ ] **T2.2** 创建 `cloudfunctions/audioConvert` 目录，配置 `config.json`（设定超时时间为 60s）与 `package.json`。
- [ ] **T2.3** 编写 `audioConvert/index.js`，实现以下步骤：
  1. 接收 `fileID`、`targetFormat`、`bitrate`、`sampleRate`、`channels` 参数；
  2. 使用 `cloud.downloadFile` 将音频拉取至容器 `/tmp` 目录；
  3. 执行 `ffmpeg` 转码并收集转码输出与时长信息；
  4. 使用 `cloud.uploadFile` 将转码结果写回云存储 `converted_audios/` 目录；
  5. 在 `finally` 块中销毁 `/tmp` 临时文件，防止容器磁盘溢出；
  6. 返回标准 JSON 响应。
- [ ] **T2.4** 云函数本地调试与云端部署指引编写。

### 阶段三：前端交互界面与配置组件
- [ ] **T3.1** 重构 `miniprogram/pages/index` 页面，搭建现代简洁、无障碍友好的工具类 UI。
- [ ] **T3.2** 封装文件选择逻辑，调用 `wx.chooseMessageFile` 过滤与校验音频文件。
- [ ] **T3.3** 渲染文件信息卡片：包含文件名、格式识别徽章、格式推荐。
- [ ] **T3.4** 实现 6 格式网格选择器，提供直观的格式说明。
- [ ] **T3.5** 实现高级音质设置折叠抽屉，支持 320k/192k/128k 码率与采样率切换。

### 阶段四：音频试听与全流程转码串联
- [ ] **T4.1** 封装音频播放组件，使用 `wx.createInnerAudioContext` 控制播放、暂停、拖动与状态监听。
