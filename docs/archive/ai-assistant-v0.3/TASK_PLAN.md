# 音乐音频格式转换小程序 - 任务规划与开发路线图 (TASK_PLAN)

## 1. 规划目标与技术基线
本项目遵循微信官方 [微信云开发快速开始指引](https://developers.weixin.qq.com/miniprogram/dev/wxcloudservice/wxcloud/basis/getting-started.html) 标准，采用**路线 A【全格式高保真版】**，基于**微信小程序原生前端 + 微信云开发 (CloudBase)** 构建端到端的全格式音频转换工具。

### 阶段二：云开发环境与核心转码云函数 (已完成)
- [x] **T2.1** 配置项目 `miniprogram/app.js` 的云开发初始化逻辑，支持动态与指定环境 ID。
- [x] **T2.2** 创建 `cloudfunctions/audioConvert` 目录，配置 `config.json`（设定超时时间为 60s）与 `package.json`（集成 `@ffmpeg-installer/ffmpeg`）。
- [x] **T2.3** 编写 `audioConvert/index.js`，实现以下步骤：
  1. 接收 `fileID`、`targetFormat`、`bitrate`、`sampleRate`、`channels` 参数；
  2. 使用 `cloud.downloadFile` 将音频拉取至容器 `/tmp` 目录；
  3. 执行 `ffmpeg` 转码并收集转码输出与时长信息；
  4. 使用 `cloud.uploadFile` 将转码结果写回云存储 `converted_audios/` 目录；
  5. 在 `finally` 块中销毁 `/tmp` 临时文件，防止容器磁盘溢出；
  6. 返回标准 JSON 响应。

- [x] **T3.5** 实现高级音质设置折叠抽屉，支持 320k/192k/128k 码率与采样率、声道切换。
