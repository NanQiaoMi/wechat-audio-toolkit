# 版权与侵权投诉指引

> 版本：v1.0 · 生效日期：2026-10-28

如你认为本小程序中由用户上传/转换的内容侵犯你的著作权、商标权、人格权或其他合法权益，请通过以下方式提交通知。我们将在核实后依法处理。

## 一、提交方式

- 小程序内：设置页 → 版权与侵权投诉（待接入客服）
- 邮箱：待填写
- 邮件标题请注明：【侵权投诉】+ 权利人名称 + 涉及内容

## 二、通知应包含

1. 权利人姓名/名称、联系方式、身份证明或营业执照；
2. 权属证明（作品登记证书、授权链、首发链接等）；
3. 涉嫌侵权内容的描述及位置（如 fileID、转换时间、文件名、截图）；
4. 侵权事实与法律依据的简要说明；
5. 真实性声明：“本人/本单位保证通知内容真实，愿承担因不实通知产生的法律责任”；
6. 授权代理人还需提供授权委托书。

## 三、处理流程与时限

1. 收到有效通知后，我们将在 **24 小时内**完成初步核实；
2. 确认侵权的，删除相关文件、断开访问，并视情况限制账号/额度；
3. 情况复杂的，最长不超过 **3 个工作日**答复；
4. 我们会将处理结果通知投诉人；无法核实的，可能要求补充材料。

## 四、反通知

被投诉人认为不侵权的，可提交反通知及权属/授权证明；我们将转送投诉人，并按法律规定处理。

## 五、注意事项

1. 恶意投诉、虚假陈述可能承担法律责任；
2. 本指引不构成法律意见；争议可依法向法院起诉；
3. 因个人主体资源有限，我们优先处理材料完整、权属清晰的投诉。
