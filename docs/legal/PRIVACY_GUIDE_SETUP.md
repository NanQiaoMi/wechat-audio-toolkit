# 隐私保护指引配置步骤（解决“无法选择文件”）

> 现象：真机点击“选择音频文件”无反应，或控制台报错
> `chooseMessageFile:fail api scope is not declared in the privacy agreement`
>
> 原因：小程序后台的「用户隐私保护指引」没有声明 `wx.chooseMessageFile`（选择文件）接口，而代码开启了 `__usePrivacyCheck__`，微信会阻止该接口。

## 一、在微信公众平台配置

1. 登录 [微信公众平台](https://mp.weixin.qq.com/) → 选择小程序；
2. 左侧「设置」→「服务内容声明」→「用户隐私保护指引」；
3. 点击「更新/编辑」，在“收集的信息”中勾选/添加：
   - **选中的文件**（或“文件”类信息）
   - 对应接口：**`wx.chooseMessageFile`**
4. 用途填写：选择用户主动从微信聊天中选择的音频文件，用于格式转换；
5. 保存并提交（如需审核，等待通过）；
6. 确认隐私指引中同时包含：`wx.chooseMessageFile`、必要的云存储/网络请求说明。

## 二、恢复代码中的隐私开关

配置完成后，将 `miniprogram/app.json` 恢复：

```json
{
  "style": "v2",
  "__usePrivacyCheck__": true
}
```

然后重新编译/生成预览，真机验证：
- 首次选择文件应弹出隐私授权弹窗；
- 同意后可正常打开聊天文件选择器。

## 三、临时开发方案

在隐私指引配置完成前，可临时移除 `__usePrivacyCheck__` 进行功能测试；**提审前必须恢复并配置好隐私指引**，否则会出现：
- 选择文件被拦截；
- 隐私弹窗不出现；
- 审核被拒/隐私检测不通过。

## 四、验证清单

- [ ] 后台隐私指引已声明 `wx.chooseMessageFile`
- [ ] 代码恢复 `__usePrivacyCheck__: true`
- [ ] 真机首次选择文件弹出隐私弹窗
- [ ] 同意后可打开文件选择器
- [ ] 拒绝后不调用文件接口
- [ ] 提审版本与后台隐私指引一致
